## Как здесь принято работать

- **Приёмка исполняемая, а не бумажная.** Скрипт с кодом возврата, а не список для галочек. В Этапе 4 бумажный протокол выглядел покрытым тестами, а исполненный нашёл три настоящих дефекта — включая бой за территорию, который не запускался вовсе.
- **Не ослаблять проверку под факт.** Красная проверка — это либо чинить код, либо выносить вопрос заказчику, но не подгонять условие.
- **Проверять по коду возврата, а не по хвосту вывода.** `npm run lint >/dev/null 2>&1; echo $?`.
- **После `prisma db push` обязателен `npm run db:raw-indexes`** — частичный уникальный индекс на открытую заявку Prisma объявить не умеет, и без этого шага уникальность исчезает молча.
- Миграции только аддитивные; значения enum добавляются отдельной миграцией.
- Комментарии в коде и документы — по-русски, объясняют «почему», а не «что».
- Временные скрипты удалять сразу: их остатки в dev-базе уже роняли тесты.
