# Stage 2: Economy Core

## Действующая спецификация

**`MASTER_TZ_STAGE_2_ECONOMY_CORE_v2.2.docx`** — версия 2.2, разделы 1–47.
Единственный источник истины. Разделы 46 и 47 — ревизии по фидбэку заказчика
от 29–30.07.2026; раздел 47 прямо помечен как имеющий приоритет над всеми
более ранними разделами документа.

Ключевое из ревизий, чего нет в версии 2.0:

- **§47.3** — единого производственного уровня нет, каждая профессия качается
  отдельно (`CharacterProfession`, `requiredProfessionCode`);
- **§47.5** — предмет описывается бюджетом очков и раскладкой, а не
  повышенными статами; улучшение = +1 очко по той же шкале.

## Устаревшее — не использовать

`*_v2.0.docx` и `*_v2.0.md` — версия 2.0 от 27.07.2026, разделы 1–45.
Оставлены для истории.

**Так делать не надо.** Копия версии 2.0 попала в репозиторий 02.08, когда уже
две недели существовала 2.2, и этот README закреплял её как authoritative.
Markdown усугубил: по нему ищет автоматика, а разделов 46–47 в нём нет —
и разработка сутки шла по модели, которую заказчик отменил. Разбор —
в `docs/STAGE2_AUDIT.md`.

Markdown-версии 2.2 нет: конвертация делалась один раз для 2.0. Если она
понадобится автоматике, конвертировать надо заново из `*_v2.2.docx`.

## Правила работы

Порядок реализации: E0 — технический долг, затем E1…E5.

Любое отступление от документа фиксируется до реализации: в коде — комментарием
у места отступления, в `docs/STAGE2_AUDIT.md` — строкой в разделе отклонений.
Пример: множитель усталости в `work.formulas.ts`.
