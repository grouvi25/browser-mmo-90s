# Этап 3 — содержимое сида

Приложение к `MASTER_TZ_STAGE_3_CRAFT_CLANS_ECONOMY`. Все таблицы кладутся в
`backend/prisma/economy-data.ts` рядом с таблицами Этапа 2 — **не в `src/`**:
рантайм-образ не содержит `src/`, сид на выкате запускается как
`npx tsx prisma/seed.ts`, и импорт оттуда уронит деплой.

Сид идемпотентен: `upsert` по `code`, повторный прогон не создаёт дублей.

# 8. Проверки сида

Расширение `scripts/check-economy-reachability.ts`:

1. У каждого рецепта каждый вход производится хотя бы одним достижимым рецептом
   или продаётся в лавке.
2. Каждый ресурс сида либо производится, либо покупается — «заведён, но
   недоступен» становится ошибкой, а не предупреждением.
3. Каждый рецепт выполним: объект достижим, профессия достижима, тир инструмента
   продаётся в госмагазине.
4. Цепочка не содержит циклов: ресурс не может быть входом рецепта, который его
   же и производит, ни напрямую, ни через посредников.
5. У каждого объекта на продажу заполнена цена, и она попадает в коридор
   окупаемости из `STAGE3_BALANCE.md`.

Пункт 4 — новая проверка: без неё легко завести `A → B → A` и получить вечный
двигатель, размножающий ресурсы.
