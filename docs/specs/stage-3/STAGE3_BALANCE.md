# Этап 3 — баланс и формулы

Приложение к `MASTER_TZ_STAGE_3_CRAFT_CLANS_ECONOMY`. Все числа отсюда попадают
в `BalanceConfig`; ни одна константа не живёт в коде формул.

Опорные величины Этапа 2, от которых считается всё остальное:

| Величина | Значение |
|---|---|
| Оклад входной смены (`obj_scrapyard`, 30 мин) | 80 ₽ |
| Оклад верхнего передела (`obj_parts_factory`, 90 мин) | 300 ₽ |
| Суточный потолок | 12 смен или 360 минут |
| Эффективность профессии | `1 + 0.03 × уровень`, максимум 1.18 |
| Усталость зарплаты | шаг 0.20, пол 0.20 |
| Госскупка ресурсов | 25% базовой цены |
| Комиссия рынка | 2%, минимум 5 ₽ |
| Налог продажи на рынке | 5% |
| Стартовые деньги персонажа | 1250 ₽ |

Ставка труда при полном дне: 360 минут смен с усталостью дают примерно
**700–900 ₽/день** на среднем переделе. Это база для всех коридоров ниже.

# 1. Производственные циклы

## 1.1. Формулы

```
laborPerShift   = shiftDurationMinutes × workerEfficiency
cycleProgress   = laborAccumulated / laborRequired
cycleEndsAt     = момент, когда laborAccumulated >= laborRequired,
                  плюс cycleMinutes календарного времени
equipmentWear   = equipmentWearPerCycle × (1 / equipmentTierSpeed)
cycleSpeed      = 1 + equipmentTierSpeedBonus × (toolTier − requiredToolTier)
```

Труд и время — две независимые оси. Труд набирается сменами, время идёт само.
Цикл завершается, когда выполнены оба условия. Один рабочий на цикл с
`laborRequired = 120` и `cycleMinutes = 60` закроет его за две смены по часу,
двое — за одну.

## 1.2. Качество выхода

```
qualityScore = professionLevel × 0.5 + (toolTier − requiredToolTier) × 1.0
             + minInputQualityBonus
minInputQualityBonus: POOR = −1, NORMAL = 0, FINE = +1
```

| `qualityScore` | Выход |
|---|---|
| < 0 | `POOR` |
| 0 … 2.9 | `NORMAL` |
| ≥ 3 | `FINE` |

Из плохого сырья отличный продукт не выходит: `minInputQualityBonus = −1`
опускает результат на ступень, и компенсировать это можно только мастером с
инструментом выше требуемого.

Влияние качества на предмет:

| Качество сырья | `statBudget` предмета |
|---|---|
| `POOR` | −1 |
| `NORMAL` | базовый |
| `FINE` | +1 |

## 1.3. Константы

```
economy.production = {
  cycleTickSeconds:        60,
  equipmentWearPerCycle:   2,        // из 100 прочности
  equipmentTierSpeedBonus: 0.15,     // за тир выше требуемого
  laborTimeoutHours:       48,       // цикл без труда отменяется
  profileSwitchCost:       1500,
  profileSwitchMinutes:    180,
  objectWithdrawTaxRate:   0.05,
  salaryRangeMin:          0.5,      // от baseSalary
  salaryRangeMax:          2.0,
  maxObjectsPerCharacter:  2,
  restorationExpMultiplier: 3.0,
  objectResaleRate:        0.5,      // продажа государству за половину цены
}
```

Обоснование `equipmentWearPerCycle = 2`: оборудование выдерживает 50 циклов.
При цикле в час это неделя активной работы объекта — владелец обслуживает
оборудование примерно раз в неделю, что заметно, но не назойливо.

# 2. Частная собственность

## 2.1. Цены объектов

Цена выведена из окупаемости: объект должен окупаться за 12–20 дней активной
игры владельца. Прибыль владельца — разница между стоимостью выхода и суммой
зарплат и сырья.

| Объект | Цена | Расчётная прибыль в день | Окупаемость |
|---|---|---|---|
| Пункт металлолома | 12 000 ₽ | ~800 ₽ | 15 дней |
| Гаражный цех | 20 000 ₽ | ~1300 ₽ | 15 дней |
| Малый завод | 32 000 ₽ | ~2000 ₽ | 16 дней |
| Фабрика деталей | 55 000 ₽ | ~3200 ₽ | 17 дней |
| Стройка кооператива | 55 000 ₽ | ~3200 ₽ | 17 дней |
| Бар | 40 000 ₽ | ~2000 ₽ | 20 дней |
| Колхоз | 45 000 ₽ | ~2400 ₽ | 19 дней |

Окупаемость бара выше намеренно: его доход зависит от чужого спроса, риск
больше, и это должно быть видно по цифрам.

## 2.2. Зарплата из баланса объекта

```
salaryPaid = clamp(salaryOverride ?? baseSalary,
                   baseSalary × 0.5, baseSalary × 2.0)
           × workerEfficiency × objectLevelCoeff × random × fatigue
```

Владелец, поставивший ставку ниже 0.7 базовой, не найдёт рабочих: интерфейс
показывает ставку в списке вакансий, и игроки выбирают по деньгам. Это и есть
рыночное регулирование, отдельного механизма не нужно.

При `balance < salaryPaid` наём блокируется с причиной `NEGATIVE_BALANCE`.
Уже начатая смена доигрывается: рабочий не должен терять деньги из-за того,
что владелец не пополнил счёт. Если баланса не хватило на выплату при клейме,
долг записывается в `maintenanceDebt` объекта и гасится при первом пополнении,
а рабочему платит система — это защита игрока, а не владельца.

# 3. Ферма

## 3.1. Участки

Сетка 4 × 3, максимум 12 участков. Первый бесплатный.

| Участок | Цена |
|---|---|
| 1 | 0 |
| 2–3 | 1 500 ₽ |
| 4–6 | 4 000 ₽ |
| 7–9 | 9 000 ₽ |
| 10–12 | 18 000 ₽ |

Полный выкуп: 108 500 ₽ — примерно 130 дней работы фермы «в ноль» или месяц
активной игры на производстве. Ферма остаётся долгосрочной целью, но не
шестизначной, как в референсе.

## 3.2. Растения

| Код | Название | Рост | Выход | Семена | Уровень | Опыт (посадка/полив/сбор) |
|---|---|---|---|---|---|---|
| `plant_dill` | Укроп | 15 мин | 2–3 `res_greens` | 20 ₽ | 0 | 1 / 1 / 3 |
| `plant_potato` | Картошка | 45 мин | 3–5 `res_vegetables` | 45 ₽ | 0 | 2 / 1 / 6 |
| `plant_hops` | Хмель | 90 мин | 2–4 `res_hops` | 110 ₽ | 1 | 3 / 2 / 12 |
| `plant_sunflower` | Подсолнух | 150 мин | 2–3 `res_oil_seed` | 200 ₽ | 2 | 5 / 2 / 20 |
| `plant_tobacco` | Табак | 240 мин | 1–2 `res_tobacco` | 380 ₽ | 3 | 8 / 3 / 34 |

## 3.3. Формулы

```
readyAt   = plantedAt + growMinutes × (1 − waterSpeedBonus × waterCount)
                                     × (1 − neighbourBonusSum)
withersAt = readyAt + (witherBaseHours + professionLevel) часов
```

```
economy.farm = {
  waterSpeedBonus:      0.10,   // за один полив
  waterMaxCount:        3,      // больше трёх поливов не ускоряют
  waterCooldownMinutes: 20,
  witherBaseHours:      6,
  farmBalanceCap:       50000,
  plotPrices:           [0, 1500, 1500, 4000, 4000, 4000, 9000, 9000, 9000, 18000, 18000, 18000],
  buildingPrices: { WATER_BARREL: 2500, CANOPY: 5000, CELLAR: 8000, DOG: 15000 },
  buildingEffects: { CANOPY: 0.10, CELLAR_PRICE_BONUS: 0.10, CELLAR_CAPACITY: 50 },
}
```

Засыхание «6 часов плюс час за уровень профессии» взято у GanjaWars и оставлено
как есть: это редкий случай, когда прогрессия снижает микроменеджмент, а не
увеличивает награду. Новичок бегает поливать, мастер собирает раз в день.

## 3.4. Коридор дохода

Целевой доход фермы — **60–80% от смены** при сопоставимом внимании игрока.

Проверка на картошке: цикл 45 минут, выход 4 единицы по 12 ₽ базовой цены,
госскупка 25% → 12 ₽ за цикл при семенах 45 ₽. Убыточно при продаже государству
— и это правильно: сельхозсырьё продаётся **барам и на рынок**, а не государству.
Целевая рыночная цена `res_vegetables` — 30–40 ₽, тогда цикл даёт 120–160 ₽
минус семена, то есть 100–150 ₽ за 45 минут против 80 ₽ за 30-минутную смену.

Отсюда правило: **госскупка сельхозсырья работает как пол цены, а не как способ
заработка**. Если рыночная цена падает ниже 2.5× госскупки, ферма перестаёт
окупаться и игроки уходят обратно на производство. Это здоровая обратная связь.

# 4. Бары и опьянение

## 4.1. Меню

| Рецепт | Категория | HP | Градус | Эффект | Себестоимость |
|---|---|---|---|---|---|
| `bar_soup` | FOOD | 25 | 0 | — | 30 ₽ |
| `bar_pelmeni` | FOOD | 45 | 0 | — | 55 ₽ |
| `bar_kvass` | DRINK | 15 | 8 | — | 25 ₽ |
| `bar_beer` | DRINK | 20 | 18 | — | 40 ₽ |
| `bar_samogon` | DRINK | 35 | 40 | — | 70 ₽ |
| `bar_chifir` | STIMULANT | 0 | 0 | +0.02 точности, 30 мин | 60 ₽ |
| `bar_energy` | STIMULANT | 0 | 0 | +3% урона, 30 мин | 90 ₽ |

Владелец задаёт цену в коридоре `[себестоимость, себестоимость × 3]`.
Налог с продажи `barSaleTaxRate = 0.20` — сток денег.

## 4.2. Опьянение

Масштаб выведен из существующей прогрессии: одна ступень улучшения предмета даёт
+0.01 к точности или +4% к урону, ступеней пять. Весь размен опьянения по модулю
не превышает четырёх ступеней.

| Градус | Название | Точность | Получаемый урон | Прочее |
|---|---|---|---|---|
| 0 | Трезв | — | — | — |
| 1–29 | Навеселе | −0.01 | −2% | +2% к урону |
| 30–69 | Пьяный | −0.02 | −4% | — |
| 70–100 | В хлам | −0.04 | −6% | нельзя нападать первым |

```
character.intoxication = {
  tiers: [
    { from: 1,  to: 29,  accuracy: -0.01, damageTaken: -0.02, damageDealt: +0.02 },
    { from: 30, to: 69,  accuracy: -0.02, damageTaken: -0.04, damageDealt: 0 },
    { from: 70, to: 100, accuracy: -0.04, damageTaken: -0.06, damageDealt: 0, cannotInitiate: true },
  ],
  soberPerHour:   34,     // полное отрезвление примерно за 3 часа
  hangoverMinutes: 60,
  hangoverAccuracy: -0.02,
  growsInBattle:  false,  // в бою градус не растёт
}
```

Правила, вытекающие из модели:

- в бою градус не растёт: напиток в бою лечит, но не пьянит — иначе боец
  переключает ступени посреди раунда и ломает расчёт;
- выход из ступени «В хлам» включает похмелье на час: −0.02 точности, пить
  нельзя. Без похмелья верхняя ступень становится бесплатным вечным баффом
  на живучесть;
- «Навеселе» — единственная ступень без штрафа. Это приманка, ради которой в
  бар заходят вообще.

## 4.3. Приёмка боевого эффекта

Прогон `scripts/simulate-apeha-matrix.ts` с каждой ступенью:
пьяный боец не выигрывает у равного трезвого чаще, чем **52%**. Порог узкий
намеренно: при 55% и выше опьянение перестаёт быть выбором и становится
обязательным для всех.

# 5. Кланы

```
economy.clan = {
  clanCreationCost:        25000,
  clanCreationMinLevel:    5,      // боевой уровень основателя
  clanMemberBaseLimit:     10,
  memberLimitPerLevel:     5,
  clanRejoinCooldownHours: 48,
  storageCapacityBase:     30,
  storageCapacityPerLevel: 15,
  storageTakeDailyLimit:   { LEADER: 999, BRIGADIER: 10, FIGHTER: 3, ROOKIE: 0 },
  treasurySpendDailyLimit: { LEADER: 999999, BRIGADIER: 20000, FIGHTER: 0, ROOKIE: 0 },
  clanMaintenanceDaily:    500,
  clanExpPerMemberShift:   1,
  clanLevelThresholds:     [0, 500, 1500, 4000, 10000, 25000],
  ownPriceDiscount:        0.10,
  allyPriceDiscount:       0.05,
  enemyPriceMarkup:        0.25,
  relationChangeCooldownHours: 24,
}
```

## 5.1. Содержание клана

`clanMaintenanceDaily = 500 ₽` списывается воркером раз в сутки. При нехватке
денег в общаке долг копится в `maintenanceDebt`; при долге выше трёх суточных
норм клан переходит в «замороженное» состояние: склад доступен только на выемку,
приглашения запрещены. Это не даёт держать мёртвые кланы ради скидок.

Стоимость покрывается взносами: 10 участников по 50 ₽ в день. Для активного
клана это незаметно, для мёртвого — смертельно. Так и задумано.

## 5.2. Цены по отношениям

```
finalPrice = listingPrice × (1 + relationModifier)
relationModifier: свой клан −0.10, союзник −0.05, нейтрал 0, враг +0.25
```

**Куда идёт разница.** Скидка уменьшает выручку продавца — он сознательно
продаёт своим дешевле. Наценка врагу **целиком уходит в налог**, продавец
получает обычную цену. Без этого правила вражда становится источником дохода,
и кланы начнут враждовать понарошку — классический эксплойт социальных систем.

Смена отношения — с задержкой 24 часа, чтобы нельзя было переключить вражду
ради конкретной сделки.

# 6. Целевые коридоры этапа

Проверяются симулятором, PASS обязателен для приёмки.

| Показатель | Коридор | Смысл |
|---|---|---|
| Доход фермы за час внимания | 60–80% от смены | ферма не вытесняет работу |
| Доход владельца объекта за час | 120–160% от смены наёмного | иначе объект незачем покупать |
| Окупаемость производственного объекта | 12–20 дней | быстрее — все владельцы, медленнее — никто |
| Окупаемость бара | 18–25 дней | риск выше, награда позже |
| Доля стоков в обороте | ≥ 40% | критерий Этапа 2 сохраняется |
| Вертикальная интеграция | 75–90% от ставки специалиста | критерий ТЗ 2.2 сохраняется |
| Победа пьяного над трезвым | ≤ 52% | опьянение — выбор, а не обязанность |
| Доля дохода клана в доходе игрока | ≤ 25% | клан помогает, но не кормит |

# 7. Новые стоки денег

Этап 3 добавляет шесть стоков — это ответ на главный риск инфляции при второй
экономической петле:

| Сток | Величина |
|---|---|
| Покупка объектов | 12 000 – 55 000 ₽ разово |
| Налог с вывода прибыли объекта | 5% |
| Смена профиля объекта | 1 500 ₽ |
| Обслуживание оборудования | детали + деньги |
| Налог бара | 20% с продажи |
| Покупка участков и построек фермы | до 108 500 ₽ разово + постройки |
| Создание клана | 25 000 ₽ |
| Содержание клана | 500 ₽/сутки |
| Наценка за вражду на рынке | 25% сделки |

Суммарно новые стоки должны съедать не меньше 40% новой эмиссии — этот
показатель уже считает `economy-metrics-daily`, порог не меняется.
