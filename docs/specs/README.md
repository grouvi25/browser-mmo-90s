## Правила работы с документами

1. **Единственный источник истины** для реализации — действующий документ этапа.
   Имена таблиц, полей, enum и констант в нём канонические.
2. **Отклонение** от документа не реализуется, пока не записано в реестр
   отклонений соответствующего ТЗ.
3. **Отменённые версии** не удаляются, но переносятся в `archive/` с баннером
   в начале файла: автоматический поиск иначе находит их раньше действующих.
4. **Числа баланса** живут в `BalanceConfig` и в симуляторе, а не в тексте ТЗ.
   Текст ссылается на коэффициент по имени.
5. **Сид-таблицы** живут в `backend/prisma/economy-data.ts` — не в `src/`:
   рантайм-образ не содержит `src/`, и сид на выкате упадёт.
