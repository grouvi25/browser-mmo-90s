# Протокол ручных QA-сценариев Этапа 2

Основание: MASTER ТЗ Этап 2 v2.2, §39.1 (39 сценариев) + сценарии 40–42,
добавленные ревизией 2.3 под новые правила труда.

| Поле | Значение |
|---|---|
| Версия сборки | _заполнить: коммит_ |
| Окружение | _прод / стейдж_ |
| Аккаунт прогона | _логин_ |
| Исполнитель | _имя_ |
| Дата начала | _дд.мм.гггг_ |
| Дата завершения | _дд.мм.гггг_ |

**Правила заполнения.** Вердикт: `PASS`, `FAIL`, `BLOCKED`. Для сценариев с
деньгами и предметами в колонку «Доказательство» вносится выписка из журнала
или ссылка на скриншот. FAIL не останавливает прогон: заводится задача, номер
задачи пишется в ту же колонку. Приёмка требует нуля FAIL.
