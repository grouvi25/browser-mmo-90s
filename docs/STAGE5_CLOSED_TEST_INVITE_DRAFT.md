## Короткая памятка для тестера (можно приложить отдельным файлом)

**Вход.** Регистрация на https://kooperativ.space, капча только при
регистрации и восстановлении пароля.

**Персонаж.** Один архетип из восьми на старте, дальше растишь три ветки
независимо: боевую, экономическую, производственную — ни одна не заменяет
другую.

**Бой.** Пошаговый, по зонам тела (голова/корпус/руки/ноги, лево-право
раздельно): выбираешь зону удара и зоны блока, дистанцию, оружие. Есть бой
с тенью (тренировочный), боты и PvP.

**Работа и крафт.** Выходишь на смену на производственном объекте — копится
труд, труд закрывает циклы, циклы дают продукцию по рецепту. Три передела:
сбор → переработка → сборка, на каждый нужен допуск с предыдущего.

**Экономика.** Рынок между игроками, госмагазин по фиксированным ценам,
бары, ремонт, кланы с общаком и территориями.

**Чего не будет — и это ожидаемо, не баг:**
- оплаты премиума картой (выдаёт админ вручную);
- банов от бота — только сигналы админу;
- тикетов для жалоб (только почта);
- новых механик сверх уже перечисленного — это тест сборки, не контента.

Полный список сознательных ограничений первой версии, если интересно
разобраться глубже: `docs/RELEASE_LIMITATIONS.md` в репозитории.

**Как сообщать о багах:** [контакт]. Формат: что делал → что ожидал → что
получил, плюс скриншот.
