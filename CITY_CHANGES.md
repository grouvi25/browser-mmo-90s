# Городские правки — 11 октября 2026

Источник: документ заказчика «Правки» (Google Docs, 1NCSrI8kOCzflWk1JFGoAgQcNonIZmnoHwJHpMXSuC5I).

## Выполнено

- Читаемые системные шрифты: Arial/Helvetica, Consolas для кода.
- Последняя локация сохраняется на сервере и восстанавливается после входа, в том числе с другого браузера. Пути проверяются по разрешённому списку.
- Убрана верхняя строка меню города; иллюстрация поднята, вкладки локаций находятся ниже. Профиль, радио и выход доступны отдельно. Мобильная версия использует потоковую навигацию.
- В Центре доступны Стрелки, Рынок, Гос магазин, Промзона, Гаражи, Мэрия, Склад, Фермы, Училище, Тюрьма, Дома бригад, ЦУМ, Берёзка, Зоомагазин и Территории.
- В каждой локации есть возврат в Центр. Рынок — существующая торговля между игроками, Гос магазин — существующие базовые товары.
- Мэрия регистрирует бригады через существующую систему; Дома бригад открывают управление, общак и склад.
- Училище продаёт существующие профессии, сохраняя их рабочую прогрессию.
- Тюрьма: модератор/суперадминистратор задаёт срок и причину либо освобождает игрока. Действие обратимо и журналируется. Сервер блокирует игровые изменения до окончания срока.
- ЦУМ: именные вещи с полностью свободным бюджетом характеристик. Распределение выполняется существующей системой Склад → характеристики предмета.
- Берёзка: экипируемый артефакт, дающий характеристику уклонения и боевой опыт в одиночных/командных/PvP боях. Сломанные и ненадетые вещи опыта не дают.
- Зоомагазин: покупка питомцев, корма, кормление, срок сытости и защита от доступа к чужому питомцу.
- Не более одной территории на бригаду: заявки, завершение захвата и частичный уникальный индекс PostgreSQL. Бонус захваченного района остаётся существующим игровым бонусом.
- Покупки идемпотентны и транзакционны; повтор запроса не списывает деньги дважды.

## Развёртывание

1. Сделать резервную копию рабочей БД.
2. Проверить, нет ли нескольких территорий у одной бригады:
   ```sql
   SELECT owner_clan_id, count(*) FROM territories
   WHERE owner_clan_id IS NOT NULL GROUP BY owner_clan_id HAVING count(*) > 1;
   ```
   Если есть — согласовать судьбу лишних районов. Миграция **останавливается**, не конфискуя их автоматически; изменения этой миграции транзакционны.
3. `cd backend && npx prisma migrate deploy && npx prisma generate && npm run db:seed`.
4. Собрать и перезапустить backend, worker и frontend. Текущий CD уже выполняет migrate и seed.

Миграция: `20261012010000_city_locations`. Никакие существующие таблицы или предметы не удаляются.
